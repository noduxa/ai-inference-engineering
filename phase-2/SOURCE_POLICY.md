# Phase 2 source policy

Last verified: 2026-09-30.

The [Phase 1 policy](../phase-1/SOURCE_POLICY.md) is shared across both phases.
Authority order for this phase is official project/vendor documentation,
original research, recognized universities, established open textbooks,
recognized technical organizations and exceptional practitioner explanations.
Primary sources define contracts; explanatory sources support understanding
without replacing them.

Use current documentation for interfaces and versioned papers for original
ideas. Record exact sections, exclusions, required/optional role, selected study
time, publication date when stated, access/terms and actual inspection date. A
missing publication date stays unknown; an inspection date is not a publication
date. Inspect page content, not only HTTP status, and follow redirects to the
real page. Bot protection/login restrictions require a recorded limitation, not
a conclusion that the academic source is invalid.

When a page changes, preserve its stable source ID if it still teaches the same
contract; record changed URL/sections and recheck dependent modules and packs.
Replace a stale source only after inspecting the alternative and explaining the
choice. Do not collect repetitive tutorials. Selected readings are free; sample
models in upstream docs may require accounts or large hardware and are not the
required lab model. Inspect model licensing independently from documentation.

NotebookLM use is manual. Import exact pages or legally obtained publisher PDFs;
verify extracted code, equations and section coverage. Do not bypass access
controls or upload private material. Store links, original notes and guidance,
not copied books, papers or course content. Cite important technical claims and
separate source statements, calculations, hypotheses and observed measurements.
