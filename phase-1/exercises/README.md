## Evidence storage

Create a dated subdirectory here only when actual work begins. Include your own
code, environment manifest, calculations and a README with exercise IDs. A
missing result stays Not started or To be validated. Do not create empty success
records.

CPU work is required where supported. NVIDIA-specific work needs compatible
hardware and remains pending if unavailable. A simulated allocation-budget error
is acceptable diagnostic practice but must never be labeled an observed CUDA
OOM.
