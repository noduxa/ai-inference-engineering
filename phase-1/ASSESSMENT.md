# Assessment system

Status: Not started. [Phase 1 home](README.md) ·
[Assessment files](assessments/README.md).

## Target level

The target is **application with early diagnostic ability**, not specialist
status. Evaluate recognition, explanation, application and diagnosis separately.
Correct terminology does not compensate for an incorrect calculation or unsafe
experiment.

## Weekly assessment

Use the [weekly template](assessments/weekly-review-template.md) within the
scheduled review time. Record an independent attempt before using sources or
NotebookLM, then record corrections separately. Link exercise evidence rather
than reporting hours as competence. Review all module concepts, including those
studied only at recognition level, with short oral checks.

## Final assessment: two-hour synthesis

| Activity                      | Minutes | Assessment                                                              |
| ----------------------------- | ------- | ----------------------------------------------------------------------- |
| Concepts                      | 20      | [Concept assessment](assessments/final-concept-assessment.md)           |
| Calculations                  | 25      | [Calculation assessment](assessments/final-calculation-assessment.md)   |
| Code reading                  | 25      | [Code-reading assessment](assessments/final-code-reading-assessment.md) |
| Debugging                     | 25      | [Debugging assessment](assessments/final-debugging-assessment.md)       |
| Teach-back and recording gaps | 25      | [Teach-back assessment](assessments/final-teach-back-assessment.md)     |

The final sitting synthesizes evidence already produced during the six weeks; it
does not include completing missing experiments. Start without generated
answers, then use the remaining time to check and annotate mistakes. Record
overtime or unfinished questions rather than silently treating them as passed.

## Completion decision

Apply the [rubric](assessments/rubric.md). Keep the learning status Not started
until work begins, In progress while evidence is being collected, and To be
validated when a result or review is pending. Only claim completion with
evidence and an explicit review record. Hardware-limited work may be documented
as a partial completion; it does not establish CUDA execution ability.

No answer keys are supplied beside the questions. Use the selected source
sections and a human reviewer or a source-grounded critique after the
independent attempt. NotebookLM feedback is advisory and must be checked; it is
not external certification.
