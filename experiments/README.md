# Experiments

**Status: Not started.** No experiment results are claimed.

For each future experiment, create a dated folder with a README, runnable code
or validated commands, pinned dependencies and reviewed evidence.

## Required record

- Question, hypothesis and initial prediction
- Hardware, OS, software versions, model revision, tokenizer and configuration
- Synthetic workload, seed, controlled variables and changed variable
- Reproduction procedure and verification checks
- Observed result and difference from the prediction
- Measurements, raw evidence, uncertainty and limitations
- Failures, blockers and alternative explanations
- Technical source links and follow-up questions

Use **Planned** until execution begins and **To be validated** for untested
steps. Do not manufacture results. Follow
[contribution standards](../CONTRIBUTING.md) and
[benchmark methodology](../benchmarks/README.md) for performance experiments.
