# AI Systems and Inference Engineering

This repository documents Joshua Nsereko’s structured transition from software
engineering, DevOps, automated testing, security and digital-health
interoperability into AI systems and inference infrastructure. It is a
transparent, evidence-based learning and open-source contribution journey,
beginning with foundational study; it does not present Joshua as an established
AI inference specialist.

## Starting foundation

Joshua brings a demonstrated foundation spanning Java and Python; backend
engineering; Docker and Kubernetes; Linux; CI/CD; Traefik and Nginx; Prometheus
and Grafana; automated testing; and application security. His digital-health and
interoperability background includes OpenMRS, OpenFn, DHIS2, FHIR and healthcare
interoperability, alongside open-source contribution and Google Summer of Code.
Experience and depth vary across these technologies; this list does not imply
equal mastery or established expertise in AI infrastructure.

## Career-development method

1. Learned programming through Java in 2019.
2. Joined OpenMRS and began contributing to open source.
3. Built credibility through visible work.
4. Participated in international opportunities, including Google Summer of Code.
5. Continued contributing until that work supported professional opportunities.

This repository applies the same method to AI inference infrastructure: study,
build, measure, share evidence, collaborate and contribute consistently.

## Long-term objective

> To become an AI systems and inference engineer capable of building, operating,
> benchmarking, securing and improving reliable model-serving infrastructure.

## Focus areas

- Python for AI systems and numerical computing
- PyTorch and transformer architecture
- GPU architecture and memory
- Model serving and inference benchmarking
- Quantization and continuous batching
- KV-cache management and distributed inference
- Kubernetes-based AI infrastructure
- Reliability, security and observability
- Open-source contribution

## Public-learning principles

- Learn publicly.
- Measure instead of guessing.
- Publish failures as well as successes.
- Prefer reproducible experiments over unsupported claims.
- Distinguish completed work from planned work.
- Build relationships by making useful contributions.
- Focus on depth rather than chasing every AI tool.
